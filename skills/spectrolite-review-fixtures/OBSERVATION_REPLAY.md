# Repeatable native observations

The live vault read shares its original independently captured vault/editor snapshot across repeated and concurrent calls. It does not repeat browser navigation or change the requested document. A failed read is surfaced and a later explicit call may retry. Handoff evidence may be read again only while the original independent vault/editor verification still passes. Repeated reads return copies; caller mutation cannot alter the native witness. This removes one-shot observation gates without changing source, vault, document, preview, navigation, content-hash, authorization or protected workspace checks. The regression accepts repeated handoff reads and rejects them when independent verification becomes false. Existing native route/edit/scope regressions remain in the focused suite.
