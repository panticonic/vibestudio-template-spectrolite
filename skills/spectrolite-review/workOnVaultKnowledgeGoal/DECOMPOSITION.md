# Open Spectrolite knowledge work

The pinned `spectrolite-live-vault` and existing open goals already use the native editor, wikilink resolver, CDP renderer receipts, canonical VCS source, and committed comparisons. The established open path verifies one final review and one authorized document write. The handoff planner already chooses draft-only, committed-review, or hold from bound preview and document receipts.

| Part | Implementation |
| --- | --- |
| Interpret a goal across linked evidence | The typed Natlang entry accumulates source, renderer and revision observations. A child chooses a visible link, evidence check, justified narrow edit, or handoff review. |
| Resolve contradictory records | A typed synthesis child weighs signed authority, replacements, tombstones, current renderer and comparison receipts. It reports the evidence actually read and which version the user may rely on. |
| Follow, read and edit the vault | Reuse native panel identity, bound CDP generation, wiki-link checks and VCS concurrency guards. A narrow owned scope authorizes a set of documents, at most one successful edit per document. |
| Replan after movement | The fixture injects a real semantic revision on one assigned document just before an edit. The existing revision guard holds the old write, and Natlang rereads and repairs from the live version. |
| Stage an authorized handoff | Reuse in-package planVaultHandoff for provenance. The exact service binds its ref, content hash, preview and recipient to the current assigned path and writes a local receipt. No outbound route or commit is exposed. |
| Verify | Independently reread canonical working and committed files and exact renderer evidence. Compare ordered links, stage reads and edits, primary decisions, protected heads and scratch handoff bytes, with negative and alias checks. |
