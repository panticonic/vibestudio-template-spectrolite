# Welcome to your default vault

This is the **default Spectrolite vault** — a folder of MDX files backed by a
workspace VCS state. It lives at `projects/default/` in your workspace and is
ready to edit out of the box.

## What you can do

1. **Edit prose** in this rich-text view — formatting renders inline,
   JSX components render live, and `[[wikilinks]]` resolve as you type.
   Embedded module and JSX blocks retain their source; use their source
   controls when you want to edit the MDX directly.
2. **Ask the resident agent explicitly** with **Ask @scribe**. Spectrolite
   first saves an exact semantic snapshot, addresses that agent by identity,
   and then sends the request. Ordinary document text never dispatches chat.
3. **Link** to other notes with `[[Wikilink Syntax]]`. Click an unresolved
   link to create the note.
4. **Publish the workspace branch** from the strip at the bottom when the
   saved changes are ready to share. The selected vault is your editing focus;
   publication currently includes the complete branch.

## Add another vault

Click the vault name in the top-left header to switch. Create new vaults
from the picker — they live as siblings under `projects/`.

## Stateful components

Components in the doc can keep private view state with `useDocState`.
That state belongs to this panel view and is not written into the document,
so clicking a component does not create a content change or affect agents.

```mdx
export const Greeter = () => {
  const [clicks, setClicks] = runtime.useDocState("greetingClicks", 0);
  const isMobile = runtime.useIsMobile();
  return (
    <Button
      size={isMobile ? "3" : "2"}
      style={isMobile ? { minHeight: 44, width: "100%" } : undefined}
      onClick={() => setClicks(clicks + 1)}
    >
      Hello — clicked {clicks} times
    </Button>
  );
};

<Greeter />
```

The `runtime.use*` hooks (`useDocState`, `useIsMobile`, `useTouchDevice`,
`useViewportHeight`) are all available inside MDX-defined components AND
in inline JSX expressions without imports. Use them to author docs that
look right on both phone and desktop.

The button renders live in the editor. Its current value is restored for this
panel view without changing the MDX.

## Declaring dependencies

Add npm or workspace packages to the YAML frontmatter and they get loaded
into the sandbox automatically:

```yaml
dependencies:
  "date-fns": "npm:^2.30.0"
  lodash: "npm:^4.17.21"
```

Inline JSX in this doc — and the agent's `eval` calls in the context of
this doc — can use those packages without redeclaring imports.
